# 0.2.0 验证范围

验证日期：2026-10-25。本节为本轮新增结果，下方保留0.1.0历史边界。

- 产品175项、计费代理26项、运行器与报告88项离线测试通过；官方DSH适配器3项本机模拟测试通过。模拟Token仅验证账本，不是实际模型成绩。
- 本机当前Codex会话的数字Token起点与中途差值已实际读取，标注为尚未包含最终回答的部分窗口。未读取认证正文或其他聊天内容，也不将研发用量混到候选任务。
- 混合流程只保留省额档；引用技能的简单问答不强制外调。外部执行接口仅文本，不向模型发送图片。
- 每次API请求即刻落盘；已确认的失败消耗保留，缺usage的请求标unknown。缓存与推理子项不重复累加。
- 集成需逐项desktop-review.json证据，绑定合同和副本哈希。程序只检查格式、完整性及绑定关系，不能证明证据真实或保证发现全部缺陷。
- Codex命令沙箱真实阻止外部、兄弟任务、越界符号链接读取和TCP访问。正式候选另禁历史、记忆、全局技能、插件、网页及子代理。
- 官方DSH SDK/runtime 0.2.1rc2通过真实本地mock协议及原生read/bash工具探针；控制区、兄弟目录、符号链接和Data卷别名读写均拒绝，模型创建命令全部断网。SDK本身仅能访问本run的模型与工具代理。
- DSH保持官方native Messages协议。因Mac禁止嵌套Seatbelt，bash工具由专属宿主执行代理在独立OS沙箱运行；没有降为裸终端，没有将C组换成Bridge执行器。

正式三组小试验已运行1题3组，原计划6题18次，余15次未开始；因C超时及尾账缺失而停止。原始轨迹和17份匹配预注册哈希的源码保存在本机私有控制目录。[真实结果](pilot-2026-10-25.md)没有证明省额，新修复尚未重新做付费对照。它是桌面总控下的受控CLI试验，不是桌面GUI性能实测，不能证明一般智能排名。官方公开题可能存在训练污染。
