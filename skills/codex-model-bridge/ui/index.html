Codex Model Bridge
本机配置

配置你的执行模型

桌面 Codex 负责规划与调度，选定的模型负责执行。只需配置 API 地址、Key 和模型，按需启用混合工作流。

快捷填入服务地址

填写兼容 OpenAI Chat Completions 的基础地址，不包含 /chat/completions。

Key 不会从配置文件回显。更换服务地址时，请输入对应服务的新 Key。

输入服务商提供的模型 ID。部分服务不提供列表，可直接手动填写。

配置保存在本机。调用模型时，Key 与任务内容会发往你填写的 API 地址，请使用可信服务。测试连接会产生少量 API 用量。

正在读取本机配置…

首次使用时，选择服务地址并填写自己的 Key 和模型。

第一次使用

  1. 填写并保存选择服务商，输入自己的 API Key 和模型 ID，再保存配置。
  2. 测试执行能力确认对话连接和工具调用都通过。模型能聊天，不一定能执行任务。
  3. 回到桌面 Codex在聊天里按需调用技能：$codex-model-bridge 帮我完成这个任务
普通任务仍默认纯 Codex。
配置模型不会自动切换工作流。只有明确调用技能时，才把执行交给外部模型。
模型填什么？

在服务商控制台找到准确的模型 ID，再粘贴到模型输入框。豆包等服务可能要求模型 ID 或推理接入点 ID，不能只填写产品名。

先保存配置再刷新列表；列表获取失败时仍可手动输入。最终以“测试连接与工具能力”的结果为准。

支持其他服务吗？

支持兼容 /chat/completions 且支持工具调用的文本模型。修改地址后需要重新输入 Key，再测试实际兼容性。

所有配置操作均通过本机服务完成规划与调度：桌面 Codex · 执行：你的模型
